>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам, после чего удаляет их и отправляет в карантин. Обычно детект называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительнее добавить исключение, но если вы не уверены в своих действиях, отключите детектирование PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован.
    * В Windows 11 Secure DNS можно настроить непосредственно в параметрах системы; [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Novanefunicular/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт.
    * Для поиска работающей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для установки стратегии в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** устанавливает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** включает или отключает отдельный режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** меняет режим обхода ресурсов из `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках показывается текущий режим:
    - `none` — IP-адреса не участвуют в проверке;
    - `loaded` — проверяется наличие IP в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет текущий фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие новых версий.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работу приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не открывается

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход); его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Novanefunicular/zapret-discord-youtube/issues/522).

### Подходящей стратегии нет
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированное в конец файла `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните изменения и проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Novanefunicular/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия иногда работает некоторое время, а затем перестаёт из-за обнаружения.
> В репозитории есть разные варианты обхода. Если готовые решения не помогают, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте вывод `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что нужный ресурс указан в списках доменов или IP-адресов.

- Испытайте другие варианты, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения есть в [#765](https://github.com/Novanefunicular/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и прочие данные.
- Перезагрузите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y.
- Удалите старую папку zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/Novanefunicular/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву, откройте свойства и, если присутствует флажок разблокировки, установите его, затем выберите применить и ОК.
- Распакуйте архив в новую папку в корне диска; в пути не должно быть пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте нужные интернет-ресурсы. Если очередная стратегия не подходит, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительное обсуждение: [#251](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выполните `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте остальные стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Novanefunicular/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее общий вариант действий:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Выясните IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Novanefunicular/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Здесь нет решения моей проблемы

- Создайте обращение [в этом разделе](https://github.com/Novanefunicular/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — исключаемые домены, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
